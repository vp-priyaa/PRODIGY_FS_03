# 🛍️ Zoopar

A Premium Local Shopping & Delivery Platform built using:

## Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- React Router DOM

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Features
- Browse Local Shops
- Become Seller
- Seller Panel
- Add Products
- Product Categories
- Favorites System
- Cart Functionality
- Dark Mode
- Flash Sale UI
- Shop Reviews & Ratings
- Chat Seller
- Product Recommendations
- City Filtering
- Responsive Luxury UI
